# hxyfront-62013 木结构榫卯构件测绘

古建筑木结构榫卯构件测绘前端。复测后现场改梁截面时，构件清单、尺寸记录表、病害标记图、
构件关系视图统一接到**同一构件版本**上，避免视图仍按旧尺寸计算、病害标记错挂构件。

## 版本与并发规则

- **同一构件版本**：一次复测的截面尺寸、榫卯类型、病害标记坐标（含标记实际所属构件）作为同一版本**一起校验**：
  - 截面宽/高/长度为正且在工艺合理范围内；
  - 榫卯工艺约束（如透榫梁高 ≥100mm、箍头榫宽高偏差 ≤15%、燕尾榫梁宽 ≥60mm）；
  - 标记坐标 0–100%，且标记所属构件必须在本建筑内（复测后标记移到别的构件也要合法）。
  - 校验全部通过才更新当前值，关系视图随即按新截面/榫卯重算（视图签名变化）。
- **两名测绘员同时提交同一构件**：平行草稿成批校验后按测量时间排序，
  只接收**测量时间最晚且校验通过**的版本为当前值；另一版**留作冲突**（`obsolete-late`）。
  测量时间不晚于当前值的版本同样留作冲突，不覆盖当前值。校验未通过的版本留作冲突（`validation-failed`）。
- **修缮建议失效**：截面或榫卯类型任一变更，旧当前值立即标记"修缮建议已失效"并转为历史版本；
  仅木材、变形等变化不影响旧建议。当前值可在清单中重新编制建议后生效。
- **本地保存失败**：提交结果落盘失败时，未提交草稿原样保留（录入区 + 本机备份），
  页面顶部横幅显示失败原因并可"重试保存"；页面重开后草稿仍在。
- **重开筛选**：建筑、榫卯类型、页签（当前值 / 冲突版本 / 历史版本）持久化，
  三类版本始终分开显示；尺寸记录表、病害标记图、关系视图只取当前值版本。

## 页面

- 构件清单（当前值 / 冲突 / 历史 三页签 + 建筑/榫卯类型筛选）
- 尺寸记录表（仅当前值）
- 病害标记图（按构件泳道展示标记坐标，标记可挂在复测后实际所属构件上）
- 单栋建筑构件关系视图（SVG，当前值版本签名驱动重算）
- 复测录入表单（支持双人平行提交；顶部可打开"模拟本地保存失败"）

## 技术栈与本地运行

React 19 + Vite 7 + TypeScript（严格模式），数据持久化在浏览器 `localStorage`。

```bash
npm install
npm run dev        # http://localhost:62013
npm run build      # 生产构建
npx tsc --noEmit   # 类型检查
```

开发端口：62013
